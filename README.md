## Featured Projects

### 🛩️ [Fly-in](https://github.com/Abdellah-Taha/Fly-in) — Drone Fleet Routing Simulator
Multi-drone routing over a weighted graph of hubs, minimizing total turns to destination.
- Two-phase scheduling: **penalized repeated Dijkstra** for pathing, **weighted round-robin** for drone assignment
- Real-time **Arcade** renderer with frame-interpolated movement
- mypy strict + flake8-clean across 4 modules

### 🧠 [call_me_maybe](https://github.com/Abdellah-Taha/call_me_maybe) — Function Calling with Small LLMs
Translates natural-language prompts into schema-compliant JSON function calls using **Qwen3-0.6B**.
- Constrained decoding via prefix-tree function-name selection
- Type-constrained parameter generation + JSON repair logic
- Pydantic-validated output schemas
